# One deliberate defect per line, as NAME @@@ FILE @@@ OLD @@@ NEW.  The
# separator is @@@ and not a pipe because Go source is full of pipes: three
# mutants of the hex decoder and the flag renderer silently failed to parse
# and were reported as NOBUILD.
# t/mutate.sh builds each one in a scratch directory and runs the whole
# suite against it; a mutant that survives is a hole in the suite and is
# written down as one rather than quietly dropped.
#
# The point is not the count.  It is that every claim in the README has
# been watched to fail: a green suite nobody has seen go red is evidence
# about nothing.
#
# One survivor, and it is equivalent rather than a hole.
# field-name-needs-two-chars starts the name scan at i+1 instead of i.
# fieldAt has already established that body[i] is a letter before the
# loop runs, and a letter is a name byte, so the loop's first iteration
# can only advance past it: the two versions compute the same length for
# every input, including a one-character name.  Left in the catalogue
# because a survivor that is deleted is a survivor nobody can check.
#
